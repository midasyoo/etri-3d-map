# ETRI 본원 3D 조감도 (공개판)

ETRI 대전본원 캠퍼스를 3D 조감도로 보여주고, **정문·후문에서 각 건물 입구까지 길을 안내**하는
웹 애플리케이션입니다. 설치 없이 브라우저만으로 동작합니다.

### ▶ 바로 실행

**<https://midasyoo.github.io/etri-3d-map/>**

또는 [`ETRI-3D-map-public.html`](ETRI-3D-map-public.html) 한 파일만 내려받아 더블클릭하면
오프라인에서도 그대로 실행됩니다. (설치·서버·인터넷 연결 불필요)

---

## 주요 기능

| 기능 | 설명 |
|---|---|
| 3D 캠퍼스 | 대전본원 16개 건물 + 운동장·주차장·저수지·산림을 위성사진 기반으로 3D 재현 |
| 건물 조회 | 좌측 목록 또는 3D 건물을 클릭하면 건물 용도와 위치 확인 |
| 길 안내 | 정문/후문 → 건물 **출입구**까지 실제 캠퍼스 도로망 최단경로(Dijkstra), 거리·도보 시간 표시 |
| 안내 캐릭터 | 사람·동물 등 23종 중 선택. 걸어가며 혼잣말·울음소리(음성 On/Off) |
| 시간·날씨 | 방문 날짜/시각을 고르면 해·노을·달(위상)·별·가로등이 그 시각에 맞게 변화. 맑음/흐림/비/눈/안개 |
| 캠퍼스 생활 | 축구·야구·족구·테니스 경기 장면, 분수, 잉어 — 야간에는 선수 퇴장 등 시간대별 연출 |
| 나침반 | 화면 회전에 연동, 클릭 시 북쪽 정렬 |

### URL 파라미터

| 파라미터 | 예시 | 설명 |
|---|---|---|
| `b` | `?b=7` | 특정 건물 선택 |
| `route`, `from` | `?route=7&from=main` | 정문(main)/후문(back)에서 해당 건물까지 경로 표시 |
| `person` | `?person=tiger` | 안내 캐릭터 지정 |
| `dt`, `weather` | `?dt=2026-09-17T19:30&weather=snow` | 방문 일시·날씨 지정 |
| `demo` | `?demo=1` | 60초 홍보 데모 자동 재생 |

## 🔒 공개판 안내 (중요)

이 저장소는 **외부 공개용**으로, 보안상 다음 정보는 **데이터 자체에 포함되어 있지 않습니다.**

- 건물의 층 구성 및 층별 도면
- 호실 번호 및 호실 배치
- 연구실·실험실 등 내부 조직 배치

건물은 **용도 분류**(연구동 / 행정·지원 시설 / 실험시설 등)로만 표시됩니다.
UI에서 가리는 방식이 아니라 **빌드 단계에서 원천 제거**하므로, 파일을 텍스트 편집기로 열어도
내부 정보를 얻을 수 없습니다.

> ETRI 구성원용(층·호실·도면 연동) 버전은 사내 배포본을 이용해 주세요.

## 데이터 출처와 정확도

- **건물 윤곽·도로망**: OpenStreetMap (대전 유성구 가정로 218 일대)
- **건물 번호·용도**: ETRI 공개 배치도(찾아오시는 길) 기준
- 일부 건물(1·4·8동, 체육동 등)은 공개 지도에 윤곽이 없어 배치도를 바탕으로 한 **근사 형상**이며,
  상세 패널에 표시됩니다. 실제 구조물과 차이가 있을 수 있습니다.
- 본 저작물은 ETRI 공식 안내도가 아닌 **개인 제작 시각화**입니다.

## 구성

```
index.html                  UI 마크업·스타일
app.js                      3D 씬, 길찾기, 캐릭터, 시간·날씨 엔진
data.js                     공개용 데이터 (건물 윤곽·도로망·경로 그래프)
lib/                        three.js r128 + OrbitControls (로컬 번들, 오프라인 동작)
tools/build_public.py       내부판 → 공개판 변환·검증 스크립트
tools/build_standalone.js   단일 HTML 파일 생성기
ETRI-3D-map-public.html     단일 파일 배포본
```
